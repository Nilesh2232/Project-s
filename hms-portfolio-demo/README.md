# Hospital Management System — Portfolio Case Study

> **Important:** This is a **sanitized portfolio / demo repository**.  
> It documents architecture, API design, database modeling, and my engineering responsibilities.  
> It does **not** contain proprietary company source code, credentials, production data, or private infrastructure details.

The production backend was built in a private company repository during my internship at **Saffotech**.  
This public case study exists so recruiters can evaluate my backend work safely.

---

## What this project is

A production-oriented **Hospital Management System backend** supporting:

- Doctor workflows  
- Nurse workflows  
- Receptionist / patient intake  
- Laboratory workflows  
- Appointments, prescriptions, queues  
- JWT authentication + RBAC  

## Highlights

| Area | Result |
|------|--------|
| REST APIs | 40+ production endpoints |
| RBAC | 50+ granular permissions |
| Database | 20+ PostgreSQL tables |
| Migrations | 15+ Alembic revisions |
| Auth | JWT + role/permission checks |
